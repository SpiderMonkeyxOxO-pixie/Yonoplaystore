## Which Android details should you compare?

An APK filename can be renamed, so `Rummy91.apk` is not enough to identify an application. Android relies on the package and signing identity to distinguish apps and authorize updates.

Before installation, record the details the source actually provides:

| Check | What should be consistent | Reason to pause |
|---|---|---|
| App label | Rummy 91 or an explained variation | Installer shows an unrelated name |
| Package name | Same package across the source and updates | Alleged update installs as a second app |
| Signing identity | Expected signer is preserved for updates | Existing app must be removed without explanation |
| Version details | Version, size and date are plausible together | Source gives conflicting version information |
| Final domain | Matches policies and support details | Download comes from an unexplained host |

If Android reports that an update cannot be installed over the current app, do not remove the old version merely to bypass the warning. First establish why the package or signer differs.

## What permissions need extra attention?

Every permission should have a feature-based reason. A connected card game may reasonably need network access or notifications. Contacts, SMS, call logs, continuous location, accessibility control, device administration and broad file access require a much clearer explanation.

Review requests one at a time. Deny anything that is not necessary for the feature you are using and check whether the app still works. Be cautious when instructions ask you to disable Play Protect, allow restricted settings or give screen-control access. Those steps reduce normal Android safeguards and should never be treated as routine.

The [App Safety checklist](/app-safety/) provides a reusable stop-or-continue test for permissions, personal data and support requests.

## What should you check before creating an account or paying?

Read the current privacy policy and terms before entering a phone number, identity document or payment information. They should identify the business handling the account, explain why data is collected and provide a working way to request help or account closure.

Separate four types of value in the interface: deposited money, promotional credit, displayed rewards and withdrawable balance. They may have different eligibility rules, verification requirements, fees and processing times. A large number on a screen is not proof that the same amount can be withdrawn.

Never share an OTP, UPI PIN, card PIN, device lock code or remote-control access with someone claiming to be support. Pause if a private contact guarantees winnings, pressures you to deposit immediately or asks for another payment to release a withdrawal. Keep receipts, transaction references and the exact support conversation if you need to raise a complaint.
